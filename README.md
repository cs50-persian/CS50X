## 📖 About This Project

This repository is part of the **CS50x Persian** initiative, created to make high-quality computer science education accessible to **Persian-speaking learners**.

The project provides Persian-language resources for **Harvard University's CS50x**, helping students learn computational thinking, problem-solving, programming, algorithms, data structures, memory management, databases, artificial intelligence, and web development in their native language.

Throughout CS50x, students are introduced to programming languages and technologies such as C, Python, SQL, HTML, CSS, JavaScript, and Flask.

Through **CS50x Persian**, Persian-speaking students can access professionally translated educational content, course materials, exercises, and learning resources designed to make the CS50x curriculum easier to follow and understand.

Our goal is simple:

**To make world-class computer science education accessible to Persian speakers. ❤️**

---

## 🎓 About CS50x

**CS50's Introduction to Computer Science** is Harvard University's introductory course in computer science, designed to introduce students to computational thinking, problem-solving, and the art of programming.

Throughout the course, students learn how to solve problems using code and develop a strong understanding of concepts such as algorithms, data structures, memory, abstraction, databases, artificial intelligence, and web development.

The course begins with **Scratch** and **C**, then introduces languages and technologies such as **Python, SQL, HTML, CSS, JavaScript, and Flask**.

The Persian edition makes these concepts accessible to students who prefer learning computer science and programming in Persian.

## 📚 What You'll Learn

Throughout CS50x, you will learn:

* C
* SQL
* CSS
* HTML
* Flask
* Memory
* Arrays
* Python
* Scratch
* JavaScript
* Algorithms
* Data Structures
* Artificial Intelligence

By the end of the course, you will have a strong foundation in computer science and programming and will be able to apply your skills to solve problems, design algorithms, build software, and develop web applications.
